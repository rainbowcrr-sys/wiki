Google Material Symbols: The Icon Font You Should Use

2026-08-23

Introduction

Material Symbols is Google's latest icon set, designed to replace Material Icons. It offers over 2,500 icons in three styles (Outlined, Rounded, Sharp) and four adjustable properties: weight, fill, optical size, and grade.

Unlike emoji-based icons, Material Symbols renders as vector outlines — they scale perfectly and can be colored with CSS.

Why Material Symbols?

  • Variable font technology — one font file, infinite variations
  • Accessibility — icons are text, screen readers can announce them
  • Performance — single HTTP request for all icons
  • Consistency — designed on a 24×24 grid

Installation

Add this line to your HTML <head>:

<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" rel="stylesheet" />

Basic Usage

Use the material-symbols-outlined class and put the icon name in a span:

<span class="material-symbols-outlined">home</span>

Code Block Component

Code blocks in this wiki use the <code-block> component — they get a language label and a Copy button automatically:

def hello(name): print(f"Hello, {name}!") hello("World")

Customization

Four axes you can control with CSS font-variation-settings:

  • Weight (100–700): 'wght' 400
  • Fill (0 or 1): 'FILL' 1
  • Optical Size (20–48): 'opsz' 24
  • Grade (-50 to 200): 'GRAD' 0

End

That's everything you need to get started. It's the cleanest, most flexible icon solution for web projects today — no emoji hacks, no SVG sprite hell.
